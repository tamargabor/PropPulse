# PropPulse - Real Estate Management PoC

## Project Overview
PropPulse is a next-generation real estate management platform built as a Proof of Concept. The goal is to explore AI-driven automation in property rental while maintaining a strict **Document-Driven Development (DDD)** workflow.

## Vision & Goals
- **Traceability:** Every architectural decision and development stage is documented before implementation.
- **Educational Value:** Understanding the synergy between .NET backends, React frontends. Use of Large Language Models (LLMs) and other AI tools if possible.

## Tech Stack
- **IDE:** VS Code, VS 2022
- **Host:** Azure
- **Backend:** C# / .NET 8
- **Frontend:** React with Tailwind CSS
